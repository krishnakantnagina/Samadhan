# Hackathon files: put everything you collect here

One folder per submission item (numbers match `docs/TICKETS.md` Phase 3 and the portal list). Drop the finished
file into the matching folder, then tick the ticket.

| Folder | What goes in it | Ticket | File type |
|---|---|---|---|
| `01-solution-synopsis/` | 1-page executive summary | T33 | PDF or DOCX |
| `02-presentation-pdf/` | Slides, 10 or fewer, for the 5-10 minute pitch | T42 | PDF |
| `03-problem-statement/` | Problem statement and proposed solution, with MP evidence | T34 | PDF or DOCX |
| `04-innovation-note/` | Innovation and differentiation note | T35 | PDF or DOCX |
| `05-impact-and-benefits/` | Impact numbers: taps, typing time, routing | T36 | PDF or DOCX |
| `06-implementation-plan/` | Feasibility plan, pilot to MP scale | T37 | PDF or DOCX |
| `07-architecture-security/` | Technology architecture, security, scalability | T38 | PDF or DOCX |
| `08-demo-video/` | 2-3 minute demo video (also note the live URL in a `LIVE_URL.txt`) | T41 | MP4 |
| `10-why-selected/` | "Why should this solution be selected" | T39 | PDF or DOCX |
| `evidence-T00-T10/` | Portal registration and cutoff confirmations (T00), 5 CM Helpline menu bot screenshots (T10) | T00, T10 | PNG or PDF |
| `backup-video-T25/` | Backup screen recording of the text flow, in case the live demo fails | T25 | MP4 |

Item 9 (the repo URL) needs no file: it is the GitHub link, `https://github.com/krishnakantnagina/Samadhan`, and the `v1-mvp` tag.

## Rules
- **Videos are not committed to git** (`.gitignore` in this folder): they are too big and go to the portal directly.
  Keep the originals here on disk and upload them from here.
- Never put keys, passwords or personal data in these files (CLAUDE.md rule).
- After the 30 Sep submission nothing in the project changes until the event ends (organizer rule), so finish files before then.
- The other files already in `submission/` (`T09-test-sentences.json`, `t09-voice-samples/`, the `T13-*` result files,
  `pitch-qa.md`) stay where they are.
